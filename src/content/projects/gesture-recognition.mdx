## The problem and constraints

An XR controller expects a steady grip and fine finger control. This project replaces it with gestures sensed from video, so the input works for people who cannot use a controller reliably.

My part is the recognition step: given a recording of a gesture, decide which gesture it is.

Three constraints shape the work:

- **Small data.** I recorded the dataset myself: 121 video recordings of 3 gestures.
- **Real-time use.** The classifier is meant for live patient input, so time per prediction matters as well as accuracy.
- **One recorder.** Every recording so far is of me.

**Three classifiers on one split, instead of one classifier.** I trained an SVM, a Random Forest and MiniRocket on the same 100 recordings and tested them on the same 21, so the comparison is like for like. They cover two approaches. SVM and Random Forest are general-purpose classifiers. MiniRocket is built for time series: it transforms each series with a large set of convolutional kernels and fits a linear classifier on the result.

**A held-out test set, instead of training accuracy.** The models never saw the 21 test recordings during training. Accuracy on the training recordings would only show that a model can memorise them.

**More than accuracy to choose a model.** All three cleared 95%, so accuracy on this split does not separate them. The choice will rest on cross-validated accuracy, time per prediction, and how each model handles a person it has not seen.

- **Dataset:** 121 self-recorded videos of 3 gestures, 100 for training and 21 held out for testing.
- **Result:** every classifier scored above 95%. With 21 test recordings, one error is worth about 4.8 points.
- **Standing:** preliminary. One split, one recorder.
- **Review:** I present results in lab meetings.

## What broke and lessons learned

**The first test could not rank the models.** With 21 test recordings, three models that all score above 95% are effectively tied. A single split also depends on which 21 recordings happen to land in the test set. The next run uses 5-fold cross-validation, so every recording is tested once and each model gets an average and a spread.

**The dataset has one person in it.** A model that recognises my gestures has not shown it can recognise anyone else’s. The project exists for patients with motor disabilities, so testing on other people’s recordings comes before any claim about them.

### Open questions I am working on

- Does the ranking of the three models change under cross-validation?
- Which model is fastest per prediction?
- How far does accuracy drop on a person the model has not seen?
